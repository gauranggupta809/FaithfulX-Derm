# FaithfulX-Derm

Empirical study: do explanation maps (Grad-CAM, Integrated Gradients) of a skin-lesion classifier
change under image perturbations, does that change signal wrong predictions, and are the highlighted
regions actually faithful (deletion/insertion vs a random control)?

## Questions
- RQ1  How do perturbation type and severity affect prediction stability?
- RQ2  How stable are Grad-CAM / IG maps, compared with a NULL (harmless) perturbation?
- RQ3  Are highlighted regions faithful? (attribution-ordered vs random-ordered deletion/insertion)
- RQ4  Does explanation instability flag misclassified images better than plain model confidence?

## Setup (VS Code terminal, from this folder)
    python -m venv venv
    venv\Scripts\activate          (Windows)   |   source venv/bin/activate (Mac/Linux)
    pip install -r requirements.txt

Set once (CMD):   set DATA="C:\path\to\skin_lesion_dataset"
(master_metadata.csv must be inside DATA, or pass --meta path\to\master_metadata.csv)

## Run order
    python src/check_data.py       --data-root %DATA%
    python src/train.py            --data-root %DATA% --epochs 8
    python src/evaluate.py         --data-root %DATA% --split val
    python src/run_stability.py    --data-root %DATA% --n-images 5      (time test!)
    python src/run_stability.py    --data-root %DATA% --n-images 200 --resume
    python src/run_faithfulness.py --data-root %DATA% --n-images 200
    python src/analyze.py

Use --split test ONLY for the final run, once, after everything else is fixed.

## Final test pass (completed 2026-11-16)
    python src/evaluate.py         --data-root %DATA% --split test --out results_test/classification
    python src/run_stability.py    --data-root %DATA% --split test --n-images 200 --out results_test/stability.csv --resume
    python src/run_faithfulness.py --data-root %DATA% --split test --n-images 200 \
                                   --out results_test/faithfulness.csv --curves results_test/curves.csv
    python src/analyze.py --results results_test --metric spearman
    python src/analyze.py --results results_test --metric cosine

Note: `analyze.py` writes fixed filenames, so a second `--metric` run overwrites the first.
Specifically, `results/instability_vs_error.csv` and `results/threshold_sensitivity.csv` in `results/` hold the **COSINE** run (the earlier `--metric spearman` run was overwritten by the second `analyze.py --metric cosine` call); recomputed validation Spearman values can be generated directly by running `python src/extra/recompute.py`, while test-split Spearman tables are preserved in `results_test/spearman/`.
Zero-map sensitivity analysis outputs (excluding all-zero Grad-CAM maps after ReLU) are saved in `results/zero_map_sensitivity.csv` and `results_test/zero_map_sensitivity.csv` (generated by `src/extra/zero_map_sensitivity.py`).

## External Assets Not Included in Archive (`master_metadata.csv`, Images, and `models/resnet18_v2.pt`)

To keep the submission archive lightweight (< 50 MB), the raw dataset images, `master_metadata.csv`, and the trained PyTorch checkpoint `models/resnet18_v2.pt` (~45 MB) are **not included** in the zip archive:
1. **HAM10000 Images & Metadata (`master_metadata.csv`)**: Download the official HAM10000 dataset from Harvard Dataverse ([https://doi.org/10.7910/DVN/DBW86T](https://doi.org/10.7910/DVN/DBW86T)) or run:
   ```bash
   python src/download_and_prep_ham10000.py --out-dir <DATASET_ROOT>
   ```
   This downloads the HAM10000 archive, extracts all 10,015 images into `<DATASET_ROOT>/images/`, and builds `<DATASET_ROOT>/master_metadata.csv` with the deterministic 70/15/15 lesion-stratified split (`random_state=42`, zero lesion overlap).
2. **Trained Model Checkpoint (`models/resnet18_v2.pt`)**: Obtained by running Phase 2 training (8 epochs on `<DATASET_ROOT>`, selecting best validation macro-F1 at Epoch 7):
   ```bash
   python src/train.py --data-root <DATASET_ROOT> --epochs 8 --out models/resnet18_v2.pt
   ```
3. **Verifying All Reported Numbers Without Re-running Training/XAI**: All raw per-image outputs from the completed validation and test runs are included in `results/` and `results_test/`. You can recompute every table, bootstrap CI, and sensitivity analysis directly from the CSVs in seconds using:
   ```bash
   python src/extra/recompute.py
   python src/extra/zero_map_sensitivity.py
   ```

## Results at a glance

| | Validation (n=166) | Test (n=165) |
|---|---|---|
| Accuracy | 0.7931 | 0.7843 |
| Macro-F1 | 0.5849 | 0.6468 |
| Confidence AUROC | 0.7374 | 0.7012 |
| Grad-CAM instability AUROC | 0.6159 | 0.6288 |
| IG instability AUROC | 0.4731 | 0.4598 |

The main findings are directionally consistent on the held-out test split. See `RESULTS_SUMMARY.md` and `paper/faithfulx_derm.pdf`.

## Rules
- Fixed lesion-level split (seed 42). Never regenerate it. Never tune on test.
- Explanations always target the ORIGINAL predicted class (fixed target).
- Report unique images/lesions, not number of perturbed copies.
- Stability is not faithfulness. Same prediction is not a correct prediction.
- Not a clinically validated tool. Do not claim novelty without a literature check.
